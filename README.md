# МедиаЛаб 3.0 — интерактивный тренажёр и аудиостудия

**Автор:** Русинов Давид, ученик 11А класса.

Учебный проект по главе 10 «Редактирование аудио и видеофайлов», стр. 185–195.

## Разделы

- Главная — начало работы
- Аудиостудия — загрузка MP3/WAV/OGG (по поддержке браузера), четыре встроенных синтезированных аудиопримера, обработка и скачивание WAV
- Уроки звука — реверберация, аудиодорожки, изменение скорости, fade in/out, частота дискретизации, форматы
- Тренажёр — 20 вопросов, порог для сертификата 80% (16 из 20)
- Словарь, карточки, правила и информация о проекте

## Аудиостудия

Звук обрабатывается прямо в браузере при помощи **Web Audio API** (OfflineAudioContext). Есть громкость, скорость, реверберация, эхо, искажение, фильтр и затухание; пресеты «Зал», «Пещера», «Радио» и другие. Для загрузки ограничение **20 МБ / 120 секунд**; встроенные примеры генерируются на устройстве (никаких чужих музыкальных записей). Готовый звук экспортируется в WAV PCM 16-bit. Не требуется ни сервер, ни регистрация. Эффекты являются учебной симуляцией, а не профессиональным мастерингом. Высота звука меняется вместе со скоростью.

## Запуск

Откройте `index.html` в современном браузере. Все три файла (`index.html`, `studio.css`, `studio.js`) должны лежать в одной папке.

## GitHub Pages

Загрузите **все три файла** в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Сертификат выдаётся при результате ≥80% и сохраняется в PNG, SVG или PDF (через печать). Это учебный сертификат без удалённой проверки подлинности.
