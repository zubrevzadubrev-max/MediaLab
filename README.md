# МедиаЛаб

Статический образовательный сайт на HTML, CSS и JavaScript. Не требует сборки и сервера: откройте `index.html` или опубликуйте папку на GitHub Pages.

## Возможности
- Главная, обучение, словарь из 36 терминов с поиском, карточки и история прогресса.
- Тренажёр: 20 случайных вопросов из банка, режимы, экзаменационный таймер, сохранение незаконченного теста и результатов в браузере.
- Учебный сертификат за результат от 80%; доступны SVG, PNG, JPG и печать в PDF.
- Аудиостудия: импорт аудио локально, 7 синтезируемых примеров, воспроизведение и обрезка, параметры обработки и экспорт обработанного результата в WAV.
- Видеолаборатория: загрузка и предпросмотр, обрезка предпросмотра, скорость, пропорции, фильтр и надпись. Экспорт смонтированного видео пока не реализован и обозначен в интерфейсе.
- Переключение светлой и тёмной темы, мобильная навигация.

## Ограничения
- MP3 экспорт не включён; WAV экспортирует сигнал после настроек обработки.
- Высота тона регулируется вместе со скоростью воспроизведения (без независимого pitch-shift).
- Видеолаборатория является предпросмотром, не полноценным экспортирующим редактором.
- Сертификат учебный, проверка подлинности без сервера невозможна.
- Google Fonts при наличии сети улучшают типографику; системный шрифт служит запасным вариантом.

Все пользовательские файлы обрабатываются в браузере; отправки на сервер нет.
